**Follow the steps to install and run the web app in your local machine**

1. Create an empty folder in your computer and CD over it your terminal using the following command: `cd <folder_name>`
2. In the same directory, clone the repository via `git clone <repository_link>`
3. Install the required python libraries in order to run the app using `pip install -r requirements.txt`
4. Run the app.py file and open the localhost server in your browser
